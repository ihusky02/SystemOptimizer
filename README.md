# SystemOptimizer
Apikacja powstała w celu nauki programowania, przy wsparciu sztucznej inteligencji.
Nie odpowiadam, za ewentualne szkody powstałe podczas użytkowania programu.
Dodano:
-Czysczenie folderu Windows.old
-Czysczenie pozostałości po Windows Update, Windows Store, i poprzednich aktualizacjach sterowników.
-Przejmowanie uprawnień, i usuwanie folderów, których nie można usunąć w standardowy sposób (np. McAfee)
-Sczegółowe informacje o dysku
